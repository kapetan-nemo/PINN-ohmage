# AGENTS.md — пакет модели (для интеграции в другие проекты)

Репозиторий: `kapetan-nemo/PINN-ohmage`. Модель `best2_cc_v5`:
прогноз кривой напряжения разряда $V(t)$ и оценка ресурса (SOH) дисковых
литий-ионных ячеек. Отчёт: `report.html` (https://kapetan-nemo.github.io/PINN-ohmage/).

---

## 1. Что внутри и как запускать

```
model/                 веса и конфигурация
  aging_net_{0,1}.pt         ансамбль сети деградации (2 инициализации)
  residual_net_{0..4}.pt     ансамбль остаточной сети поправки ΔV(SOC) (5)
  config.json                опции инференса, протокол, эталонные метрики
coin_cell_pinn/        код: загрузчики, характеризация, сети, инференс
inference.py           пример сборки конвейера по config.json
smoke_test.py          проверка: веса, инференс сетей, монотонность
report.html, figures/  научный отчёт и иллюстрации
```

```bash
pip install -r requirements.txt      # torch, numpy, scipy, pandas, pyyaml
python smoke_test.py                 # веса + forward + монотонность
python inference.py                  # читает model/config.json, собирает конвейер
```

Метрики на независимой контрольной выборке (13 ячеек, 3246 циклов, leave-one-battery-out):
RMSE напряжения 23,1 мВ, MAE SOH 0,37 %.

## 2. Требования к входным данным

- **Что подаётся**: разрядные сегменты (гальваностатический разряд до отсечки),
  по одному на цикл, плюс ранние циклы той же ячейки для первичной характеризации.
- **Сколько**: ≥ 2 ранних цикла (рекомендуется 3–4 подряд, без формационных);
  ≥ 1 измеренного цикла истории (рекомендуется ≥ 5, валидировано до 382 циклов);
  общий горизонт — до 400+ циклов.
- **Сколько точек на цикл**: ≥ 50, рекомендуется 300–600 (загрузчик прореживает
  равномерно; сырая дискретизация ≤ 1 с).
- **Прочее**: изотермия ±1 °C; паузы > 60 с между фазами для сегментации; SOC берётся
  из счётчика ёмкости разрядной фазы либо интегрированием тока.
- **Чего модель не делает**: зарядные фазы и релаксация не моделируются; импульсные
  токовые профили не валидированы; прогноз ёмкости — на один цикл вперёд.

## 3. Как интегрировать

```python
import sys; sys.path.insert(0, "<path>/best_2")
from coin_cell_pinn.dataset_engine import CellData, CoinCellDataPipeline
from coin_cell_pinn.population import characterize_cell, Normalizer
from coin_cell_pinn.best2cc import eval_config, tail_grid
from inference import load_model

cfg, aging_nets, residual_nets = load_model("model")

# 1) свои данные → CellData: список разрядных сегментов одной ячейки
cells = [...]                       # t(с), i(А, разряд>0), v(В), soc, q_max_ah, cycle_n
# 2) первичная характеризация (R0, Q0, V-окно)
comm = characterize_cell(cells, cfg_yaml, run_dir="runs/ecm_mycell")
# 3) прогноз по циклам: для каждого цикла N используются только данные N' < N
rows = eval_config({cell_id: cells}, {cell_id: comm}, aging_nets, residual_nets,
                   cfg_yaml, tail_grid(), q_model="median",
                   rate_norm=True, rc=True, collect_curves=True)
# rows[0]["rmse_v_mean_mv"], ["soh_mae_pp"], ["curves"] — метрики и покомпонентные кривые
```

Полезно знать:
- `CellData` — один разрядный сегмент одного цикла; разряд определяется по падению
  напряжения (конвенция знака тока у разных тестеров различается).
- Если в данных есть циклы при пониженном токе (референсные), `rate_norm=True`
  нормирует SOH по скорости; без них — оставить `rate_norm=False`.
- Опции инференса зафиксированы в `model/config.json` (`options`): медианная
  экстраполяция ёмкости, нормировка SOH по скорости, RC-динамика, SOC-сетка
  с уплотнением у отсечки, ансамбль пяти остаточных сетей. Менять их без
  повторной валидации не следует.

## 4. Правила для агентов, работающих с этим репозиторием

- Веса и код в `main` — опубликованная версия; изменения только через новый прогон
  в материнском репозитории (`scripts/best2_cc.py`) + сверку на контроле + новый экспорт.
- Датасеты в репозиторий не добавлять (см. DOI в `report.html`).
- Страница отчёта обслуживается веткой `gh-pages` (файлы `index.html`, `report.html`,
  `figures/`); при обновлении отчёта синхронизировать обе ветки.
- Терминология и стиль отчёта: академический русский, «первичная характеризация»,
  «кросс-ячеечная валидация (leave-one-battery-out)», формулы и рисунки нумеруются
  по порядку упоминания.
