## Описание

Двухконтурная модель для малогабаритных дисковых (coin cell) литий-ионных ячеек:

- **внутренний контур** — эквивалентная схема Thevenin второго порядка (2RC):
  идентификация омического сопротивления, постоянных времени и эмпирической
  характеристики разомкнутого напряжения по нескольким ранним циклам
  (первичная характеризация);
- **внешний контур** — рекуррентная регрессия ёмкости по измеренной истории
  предыдущих циклов с нормировкой по скорости разряда; прогноз ёмкости строится
  медианной экстраполяцией.

Прогноз напряжения на произвольном профиле тока выполняется интегрированием
динамической модели; обучаемые компоненты отвечают за эмпирические
характеристики и поправку межциклового дрейфа.

## Схема прогноза

```
измеренный разрядный цикл (V, I, дискретизация 1 с)
        │
        ▼
   OCV-таблица: три последних измеренных цикла,
   экспоненциальные веса свежести (τ = 5 циклов)
        │
        ▼
   коррекция ΔV(SOC) — ансамбль пяти сетей
        │
        ▼
   интегрирование ОДУ 2RC с идентифицированными R₁C₁, R₂C₂
   (аналитический шаг, Δt ≤ τ/5)
        │
        ▼
   V(t)  +  SOH (медианный наклон последних ≤5 измеренных циклов)
```

Полное описание метода, уравнений и протокола — `report.html`, раздел 3.

## Требования к входным данным

- ранние циклы: ≥ 2 (рекомендуется 3–4 подряд, без формационных);
- история измеренных циклов: ≥ 1 (рекомендуется ≥ 5; валидировано до 382);
- измерений на разрядный цикл: ≥ 50, рекомендуется 300–600;
- дискретизация ≤ 1 с; температура стабильна ±1 °C;
- гальваностатический разряд до отсечки; паузы > 60 с между фазами.
