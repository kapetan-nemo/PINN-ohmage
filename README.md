## Описание

Двухконтурная модель для малогабаритных дисковых (coin cell) литий-ионных ячеек:

- **внутренний контур** — эквивалентная схема Thevenin второго порядка (2RC):
  идентификация омического сопротивления, постоянных времени и кривой
  разомкнутого напряжения по нескольким ранним циклам («первичная характеризация»);
- **внешний контур** — рекуррентная регрессия ёмкости по измеренной истории
  предыдущих циклов; прогноз строго монотонен.

Режим предсказания не требует переобучения: кривая напряжения на произвольном
профиле тока генерируется интегрированием динамической модели, а обучаемые
компоненты отвечают лишь за эмпирические характеристики.

## Схема прогноза

```
измеренный цикл (V, I, 1 с)
        │
        ▼
   OCХ-таблица (3 последних измеренных цикла, экспоненциальные веса свежести, τ = 5)
        │
        ▼
коррекция ΔV(SOC) — ансамбль 5 сетей
        │
        ▼
интегрирование ОДУ 2RC (аналитический шаг, Δt ≤ τ/5)
        │
        ▼
V(t)  +  SOH (медианный наклон последних ≤5 измеренных циклов)
```

Полное описание метода, уравнений и протокола — `report.html`, раздел 3.

## Требования к входным данным

- ранние циклы: ≥ 2 (рекомендуется 3–4 подряд, без формационных);
- история измеренных циклов: ≥ 1 (рекомендуется ≥ 5; валидировано до 382);
- измерений на разрядный цикл: ≥ 50, рекомендуется 300–600;
- дискретизация ≤ 1 с; температура стабильна ±1 °C;
- гальваностатический разряд до отсечки; паузы > 60 с между фазами.
